Features

Everything a lecture needs

Automatic capture

Saves each new slide the moment it appears, cropped to the slide. Duplicates are skipped and it pauses while a video plays.

নতুন স্লাইড এলেই সেভ, একই স্লাইড দুবার না।

Capture Now

One click (or the phone button) saves the current screen whenever you want it.

যখন দরকার, এক ক্লিকেই।

Class schedule

Set your class times once. SNapp starts and stops capturing on its own.

ক্লাসের সময় বসাও, বাকিটা SNapp-এর।

Phone remote

Scan a QR code and capture from your seat. See the latest slides as thumbnails. Works on your local Wi-Fi only.

QR স্ক্যান করো, ফোনই রিমোট।

Google Drive backup

Every slide goes to My Drive › SNapp › date. No internet? It waits and uploads later.

সব স্লাইড তারিখ অনুযায়ী Drive-এ।

Quiet in the tray

No pop-ups. Lives in the system tray and can start with Windows.

চুপচাপ ট্রে-তে, কোনো ঝামেলা নেই।
Install

Ready in a minute

Download

Click Download for Windows to get SNapp-Setup.exe.

Install

Open it and click through. No admin rights needed. You get Start Menu and Desktop shortcuts.

Start capturing

Open SNapp, pick your screen and click Start capture, or add your class times.

Windows protected your PC? SNapp is new and not yet code-signed, so Windows SmartScreen may warn the first time. Click More info → Run anyway. প্রথমবার Windows সতর্ক করলে More info → Run anyway চাপো।

Your slides stay yours

Everything is saved on your own PC. Google Drive backup is optional, and SNapp can only see the files it uploads itself. Nothing is sent to us. Read the privacy policy.
